# Final release audit

This workspace verifies the current release candidate; it adds no product feature.
Synthetic fixtures contain no user credentials or private history. Public-user
checks retain aggregate reports, not new raw personal datasets.

- `fixtures/golden-user.json`: hand-inspectable completed games, puzzle events and evaluation pairs.
- `fixtures/golden-expected.json`: literal hand-counted controls, not generated by the extension.
- `verifier/independent.py`: Python standard-library implementation reading raw records only. It must never import `src/` or consume extension-normalized input as its source of truth.
- `verifier/collectExtension.ts`: adapter executing the actual extension pipeline; this is the implementation under test, not the independent oracle.
- `reports/`: comparisons, invariants, stress measurements and reproducible audit evidence.

Deterministic counts and timestamp/duration sums require exact equality. Floating
ratios use at most `1e-10` absolute tolerance, documented per metric. Unavailable
data remains null; missing observations are not zeros. Reports identify synthetic
versus public sources, timezone, reference clock and every unverified gate.

The final release decision is in `../FINAL-AUDIT.md`. Mandatory checks that cannot
run in this environment are not marked PASS.

Run `npm run audit:data` from the repository root (Python 3.9+ with IANA timezone
data and Node 24). On Windows, Python's `tzdata` package may be needed if ZoneInfo
is unavailable; the audited host already provides it. The command calculates the
oracle, runs the actual IndexedDB/React pipeline in four isolated timezone
processes, and writes the exact comparison CSV. CI runs the same command.

`publicCheck.ts` samples the latest archive of three public usernames through
PubAPI. Bundle it with esbuild into ignored `audit/temp/` and run the bundle with
Node. The report contains counts and comparison outcomes only. Public puzzle
history is unavailable, and public duration fallbacks are outside this oracle's
scope; those paths have separate literal regression tests.

After `npm run build` and `npm run release:pack`, run
`python audit/verifier/hygiene.py`. It checks strict credential formats in working
text and reachable local Git history, then inspects the ZIP and checksum. It never
prints matched credentials. These are limited release controls, not a replacement
for the independent Codex Security scan or a clean-profile browser install.
