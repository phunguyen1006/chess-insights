# Chess Insights v0.1.6 — Reliability fixes

This preview fixes reproducible correctness and lifecycle issues found by a project-wide test/review pass. **209 tests in 29 files pass**, including 51 additional regression tests; typecheck, ESLint, normal/debug builds and production packaging pass.

## Changes

- Home heatmap recovers when the native renderer removes it or replaces cards. Full-width placement is retained; redundant footer text is removed.
- Archive sync keeps waiting requests after failures, preserves manual refresh intent and handles UTC rollover/CDN settling correctly.
- Settings writes cannot overwrite concurrent partial updates; malformed API data and blocked database upgrades recover cleanly.
- Puzzle save/OFF/Clear are ordered; pending old completions do not reappear after Clear. Hidden/stale result metadata, account changes and damaged session storage are handled conservatively.
- Engine startup, Pause/Cancel, stop/resume and watchdogs are guarded by run identity; old workers cannot modify a new run. Review grading retains concurrent history and blocks duplicate clicks.
- Account changes reset confirmations and stale UI responses; month-based date filters clamp to shorter months.
- ZIP creation verifies required runtime assets, licenses, version consistency and production/debug status before publishing.
- Development fixtures load the version correctly, and generating a release ZIP no longer crashes the Windows watcher.

## Installation / upgrade

Download **chess-insights-v0.1.6.zip**, extract it and load the directory containing `manifest.json`. **SHA256SUMS.txt** verifies the ZIP. Automatic Source code archives require building.

Existing users: replace files in the **same extension directory**, then reload the existing extension and Chess.com. Keep its identity to preserve games, puzzle attempts, analysis and review history. Permissions and database schema are unchanged. GPL/third-party licenses and the exact bundled Stockfish source remain included.

## Verification and limits

Local fixtures verify all eight Insights sections, desktop/390px sizing, SPA mounting and real local Stockfish WASM. The heatmap matches Play Online at 1057px and sits above both native cards in the reported-grid fixture.

Authenticated Chess.com puzzle metadata and real extension offscreen delivery still need final verification in the user's normal Edge/Chrome profile, so this remains a **pre-release**. Puzzle history before tracking begins cannot be recovered; Daily Puzzle, Rush and Battle remain excluded.
