# Chess Insights v0.1.8 — Native Stats, Play Time and Sessions

This preview adds observed game-duration analytics and redesigns the existing Insights interface using Chess.com's Stats layout as its visual reference.

## New

- Play Time from validated PGN Start/End headers, reliable move-clock reconstruction or complete elapsed-move annotations. Daily and puzzle time are excluded; missing data stays unknown and coverage is always visible.
- Lazy, versioned duration caching through an additive IndexedDB v4 upgrade. Existing games, puzzles, engine analyses and review schedules are preserved.
- Play Time on Overview, a separate Activity heatmap metric, and Time charts for monthly totals, pool shares, average duration, distribution, longest games and records.
- Sessions from observed intervals with a 30-minute gap; session length trends, coverage, per-pool observed rating changes, recent sessions and performance by game number.

## Interface

- Cyan area trends, compact summary rows, gray Highlights headers, native-style tables and two primary pool/period selectors.
- Rating: a dominant graph/value, All Games / White / Black, Highlights and Average Opponent Rating.
- Time: Overview / Play Time / Clock Usage / Time Pressure / Sessions. Existing clock analytics remain available.
- Results, Openings, Opponents and Mistakes use structured rows, tables and horizontal comparisons. Detailed analytics, engine queues and review remain accessible.
- The homepage retains its full-width green/white Games + Puzzles calendar.

## Verification and scope

Public fixture: 72/72 eligible real-time games have observed durations, totaling **3h 12m 53s**, with **53 sessions**. Five real PGNs were manually checked against both header and clock paths. Desktop and 390px screenshots, real local Stockfish computation and review grading were inspected.

**333 tests in 43 files**, typecheck, ESLint and the verified production build pass. Production-redacted snapshots are covered by integration regression tests; existing data survives the populated-store migration tests.

See the [full implementation and QA report](https://github.com/phunguyen1006/chess-insights/blob/v0.1.8/docs/QA-0.1.8.md) and [PGN calculations](https://github.com/phunguyen1006/chess-insights/blob/v0.1.8/docs/PLAY-TIME-VALIDATION.md). Live authenticated Chess.com mounting/theme and extension-origin offscreen delivery still need final manual Edge verification.

## Upgrade

Download **chess-insights-v0.1.8.zip** and replace the files in the same unpacked-extension folder. Reload the existing extension and Chess.com. Keep the same folder/extension identity and export a puzzle backup before changing storage. No new permissions are requested. Automatic Source code archives are development source, not the installable package.

The release includes the installable ZIP and SHA-256 checksum, all required licenses and the corresponding bundled Stockfish source. This is independent community software, not an official Chess.com product.
