# Chess Insights v0.1.5 — Puzzle Activity preview

The first public release of Chess Insights, a standalone Chrome/Edge extension for historical Chess.com analytics and local rated puzzle activity tracking.

## Included

- Full-width green/white Games + Puzzles activity calendar below Play Online and above Recommended Match + Daily Puzzle.
- Insights sidebar entry with Overview, Activity, Rating, Openings, Opponents, Results, Time and Mistakes.
- All Activity / Games / Puzzles, outcome/success statistics, charts, streaks, observed puzzle rating and records.
- Local rated-puzzle tracking, durable deduplication, per-account start dates and live updates across open tabs.
- ON/OFF tracking, confirmed puzzle-only history clearing and an additive v2 → v3 database upgrade preserving existing history and analyses.
- Bundled Stockfish 18 lite WASM for on-demand review of completed stored games. No engine assistance on active games or puzzles.

## Downloads

Download **chess-insights-v0.1.5.zip**, extract it and load the folder containing `manifest.json` as an unpacked extension. **SHA256SUMS.txt** verifies the ZIP. The automatic Source code archives require building and are not the installable package. The extension ZIP includes installation instructions, GPL license, third-party licenses and the exact bundled Stockfish source archive/rebuild notes.

For an update, replace files in the same existing extension directory, then click Reload. Do not uninstall, change the extension path, clear storage or load a duplicate if you want to keep local history. See [installation instructions](https://github.com/phunguyen1006/chess-insights/blob/main/docs/INSTALL.md).

## Data and permissions

Completed game history comes from Chess.com's public PubAPI. Puzzle history is recorded locally from eligible completed rated attempts after tracking begins; earlier puzzle history is not available. No telemetry, private API, server or puzzle answer extraction is used. Permissions remain storage/offscreen plus Chess.com and PubAPI host access.

## Validation and preview status

Local validation passed: **158 tests in 21 files**, typecheck, ESLint, production/debug builds and package/manifest verification. Fixture browser checks verified solved/failed persistence, 50% success for one of each, cross-tab updates, one mount and full-width placement. GitHub CI independently runs installation, all checks, build and ZIP packaging.

This is a **pre-release** because authenticated Chess.com result panels and narrow-window integration still require manual verification. Detection uses semantic anchors and conservatively skips unknown completion/next-session signals. Daily Puzzle, Rush and Battle are not tracked. No historical puzzle backfill is included. See [verification scope](https://github.com/phunguyen1006/chess-insights/blob/main/docs/VERIFICATION.md).
