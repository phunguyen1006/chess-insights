# Chess Insights v0.1.7 — Puzzle backups and game exports

This preview adds a way to keep recorded puzzle history outside the browser and export filtered games to a spreadsheet. It also fixes two Mistake Bank queue/review issues. **258 tests in 32 files pass**, plus typecheck and ESLint.

## Changes

- **Puzzle JSON backup:** Settings → Puzzle history backup downloads the selected account's recorded attempts. Choose a saved file, check its preview and select **Merge puzzle history** to add missing attempts. Existing attempts stay unchanged; importing again does not create duplicates.
- **Validated local restore:** wrong-account files, malformed records and conflicting duplicate IDs are rejected. Imports are limited to 20 MB per file and 50,000 attempts in the merged account history. Failed imports roll back without partial writes.
- **Honest coverage:** import preserves the current tracking setting and tracking/Clear boundary. Older restored attempts appear on their original local calendar dates, with a notice that other attempts may be missing. A fresh destination starts its coverage boundary at import time.
- **Filtered game CSV:** export the currently selected cached games in 16 columns with UTF-8 encoding, CSV quoting and spreadsheet formula protection. The export follows the current filters and does not fetch additional archives.
- **Mistake Bank fixes:** the primary Retry button resumes the existing pending queue. Late grading responses cannot reopen a closed review or overwrite a new session; starting another review hides the previous answer.

## Installation / upgrade

Download **chess-insights-v0.1.7.zip**, extract it and load the directory containing `manifest.json`. Use **SHA256SUMS.txt** to verify the ZIP. GitHub's automatic Source code archives require building first.

Existing users: replace files in the **same extension directory**, then reload the existing extension and Chess.com. Keep its identity to preserve all local data. After upgrading, download a puzzle backup from Settings. Permissions and database schema are unchanged. GPL/third-party licenses and the exact bundled Stockfish source remain included.

## Backup scope and verification limits

A puzzle backup restores only attempts previously recorded by Chess Insights. It cannot retrieve unrecorded past attempts from Chess.com and does not include games, engine analyses, review schedules or settings. A game CSV is a spreadsheet export, not a restorable extension backup. Both types of files contain account/activity data and stay local unless you choose to share them.

This remains a **pre-release**. Authenticated Chess.com puzzle metadata, exact native DOM integration and real extension offscreen delivery still require final verification in a normal Edge/Chrome profile.
