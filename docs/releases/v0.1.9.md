# Chess Insights v0.1.9 — Unanalyzed games and Light/Dark mode

This preview release replaces the six analysis scopes with one **Unanalyzed games** option. It loads available public archive years, shows the number of eligible remaining games, and queues all of them without the old 10/20-game limit. An earlier completed batch no longer hides other pending games. Compatible cached analyses are reused; invalid and unsupported games are reported separately. Page filters continue to control statistics rather than analysis selection.

**Settings → Appearance** now offers **Light mode / Dark mode** for Insights and the homepage heatmap. The choice is saved on the device and propagated to other open extension surfaces. Tables, charts, labels, controls and tooltips use the corresponding palette.

Existing game history, puzzle data, analyses and review schedules are preserved. No new permissions, dependencies or database changes. Local Stockfish remains restricted to completed historical games; keep Mistakes visible and the device awake while analyzing. Pause/Resume retains finished games and pending work.

Verified by 343 automated tests in 45 files, typecheck, ESLint, production-build/package checks, local desktop/mobile theme tests and a real Stockfish queue exceeding 20 games. Authenticated Edge DOM integration and production offscreen-engine startup still require final manual verification. See [detailed verification](https://github.com/phunguyen1006/chess-insights/blob/main/docs/QA-0.1.9.md).

Download **chess-insights-v0.1.9.zip** and extract it into the same permanent folder as the existing unpacked extension, then reload the extension and Chess.com. Keep the same extension identity to retain local data. The accompanying **SHA256SUMS.txt** file verifies the ZIP. GitHub's automatic source archives must be built before loading.
